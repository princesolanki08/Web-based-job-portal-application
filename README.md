Web-Based Job Portal Application

A full-stack Job Portal Application developed using Java, Spring Boot, MySQL, and React.js that helps connect recruiters and job seekers through a modern and user-friendly platform.

The application allows recruiters to post and manage job openings, while candidates can search, filter, and apply for jobs online. It is designed to simplify the hiring process with secure authentication, responsive UI, and efficient backend services.
